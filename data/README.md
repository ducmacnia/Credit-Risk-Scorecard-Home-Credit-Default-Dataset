# Data Folder

Thư mục này dùng để chứa dữ liệu Home Credit Default Risk sau khi tải từ Kaggle.

Không đưa dữ liệu raw lên GitHub. Hãy tạo thư mục `raw/` tại đây và đặt các file CSV vào:

```text
data/raw/
├── application_train.csv
├── application_test.csv
├── bureau.csv
├── bureau_balance.csv
├── previous_application.csv
├── POS_CASH_balance.csv
├── installments_payments.csv
├── credit_card_balance.csv
└── HomeCredit_columns_description.csv
```

Nguồn tải dữ liệu:

https://www.kaggle.com/competitions/home-credit-default-risk/data
